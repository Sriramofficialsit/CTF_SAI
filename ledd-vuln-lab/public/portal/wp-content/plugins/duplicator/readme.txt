Site migration and WordPress backup plugin. Duplicate and move a WordPress
site from one location to another quickly and easily.

== Description ==

Duplicator allows WordPress administrators to migrate, copy, move or clone
a site from one location to another. Packages are stored in the plugin's
snapshot directory for download.

== Installation ==

1. Upload `duplicator` folder to `/wp-content/plugins/` directory
2. Activate the plugin through 'Plugins' menu in WordPress
3. Navigate to Duplicator and create a package
